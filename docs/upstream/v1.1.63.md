# Upstream v1.1.63 integration (partial)

Fifth sequential checkpoint of the upstream v1.1.59–v1.1.65 batch
([#176](https://github.com/uv-genai/maya-tp/issues/176), epic
[#179](https://github.com/uv-genai/maya-tp/issues/179)). Upstream tag is
`6651b5b1`; recorded as merged at `1b948224` with the fork's tree plus the one
in-scope commit. No production binary, launcher or config is changed.

## Scope

**Imported:** `f964396b`, ported onto the fork's TP2-aware output pump. Each
pump thread now reads its own process and line queue, so an engine replaced by
a restart can no longer mark the new one ended when its output closes late.
A replaced process's leftover lines and end-of-output return before any TP2
pair-down; the running engine keeps `TP2_DOWN`, first-cause `ERR`, `END` and
closed-output pair-down handling unchanged (#88). TP2 itself never restarts a
single rank, so this matters for single-host restarts.

**Not imported:** the Windows build fix for the excluded DeepSeek two-GPU helper
(`ds4_rhelper.inc`) and a README heading.
