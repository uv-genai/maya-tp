# Upstream v1.1.64 integration (partial)

Sixth sequential checkpoint of the upstream v1.1.59–v1.1.65 batch
([#177](https://github.com/uv-genai/maya-tp/issues/177), epic
[#179](https://github.com/uv-genai/maya-tp/issues/179)). Upstream tag is
`d93d1499`; recorded as merged at `5310f627` with the fork's tree plus the
in-scope commits (the AMD + NVIDIA pairing stays excluded, per the v1.1.62
decision). No production binary, launcher or config is changed.

## Scope

**Imported:** `64cd7ac8` native expert layers whose gate and up differ in type
(shared CPU/device expert kernels and layout; same-type layers keep exactly
their code), with `native_mixed_test`; `6d04eef7` DeepSeek's PCIe-lane tie rule
on a local layer split or `--tp` (#956; one GPU, as on each TP2 rank, keeps
#697's rule); `7394a9ec` maya-mm3 router NaN diagnostics (#672); `4146632b` /
`4d58a355` the MiniMax setup checks GGUF files already in place by sha256.

**Not imported:** GLM link mode with EXL3 packs (six commits), the helper
program's 1 GB RAM-tier registration, their SETTINGS note, README speed rows.

## Validation

`tools/local_gates.sh` passes at `5310f627` (991 server tests, 32 skips; 962
tools tests, 5 skips; every CPU suite). Engines frozen on both hosts
(identical): GLM `52113c3c…`, DeepSeek `852a30eb…`, MiniMax `8931790c…`.
`native_mixed_test` and `mm3_wscan_test` pass on gfx1151; the nine
pre-bootstrap refusals pass.

All six GLM Maya-S / DeepSeek XS/S default1 and batch2 cases match the frozen
v1.1.63 results token for token (0 differences) with identical MTP/DSpark
proposal counts; false-valued `NO_*` reach, the Chinese whole-head fallback,
batched cancellation/refill/reuse and first-fatal fanout (0.656 s GLM / 0.814 s
XS) pass.

One GLM two-slot long-prompt speculative decode read 30.75 tok/s (33.69 in
v1.1.63) while every other decode figure stayed in its range. Because the
shared expert kernels changed, a matched repeat alternated the frozen v1.1.63
and v1.1.64 engines twice: 33.73 / 32.63 (v1.1.63) vs 33.78 / 33.42 (v1.1.64)
tok/s, all outputs identical. There is no regression; the low reading did not
recur.
