## Semantic integration

The normal DeepSeek streamer's per-chunk picked-expert policy is integrated
with the existing sliced RAM staging. Routing publication and copy selection
both use the same per-chunk policy, and streamed virtual slots start at `pv_n`
(including lent-slot layout). The new shallow-ring prefetch and local drafter
placement policies do not replace the remote RDMA TP2 path. The fork retains
400 MB staging rings by default and explicit `DS4_RING_MB=link` selection.
The new local `draft_spread` policy is separate from the deferred v53
`draft_gpus` experiment. The latter is not accidentally reintroduced as merge
context. The gfx11 indexer matrix path stays opt-in (`DS4_INDEX_TC=1`), preserving
the fork's output behavior pending scoped quality validation.

Qwen catalog/history/monitor changes, ROCm discovery and guarded upstream
kernel changes are integrated. Split ROCm installations retain their existing
HIP_PATH handling and TP2 RDMA builds. Pinned llama.cpp and numeric VERSION
remain unchanged. Existing text-only HIP Qwen behavior is preserved; unrelated
previously excluded Windows/vision/placement helpers are not imported through
conflict context. No model is downloaded.

The server retains serialized complete commands, per-request state and sticky
first-fatal fanout. Health includes both TP state and upstream's new history
field. The fork-owned README, AGENTS and operational guides are edited
semantically. No production executable/config or protected peer checkout is
changed.
