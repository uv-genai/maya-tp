caller's whole-vocabulary MTP fallback for non-Latin output. Remote single-slot
NextN execution remains on both ranks with canonical forced inputs; batched
proposal/verdict handling retains its separate checked protocol. Explicit
rank-local KDA descriptors and all corrected snapshot/checkpoint/slot copy
sizes from v57 remain intact.

`ablate` before changing state; paired configuration/model-setting injection
is refused, capability is hidden, and the installer skips direction acquisition
for paired configs. No direction file is downloaded by this validation.

slot generations, first-fatal retention and post-failure write guards remain.

sum hooks or the fork's sequence/capacity methods. Deferred local flow-DMA and
CUDA lane-parity context is not reintroduced. Inherited one-GPU PCIe timing
changes are imported without promoting that path onto remote HIP TP2.

Full GLM-5.3 catalog/calibration and Q8_0 attention packing changes are scoped
to the full-model identity. Existing Flash packs are not repacked; Flash defaults,
ROCm split paths, RDMA configuration and llama.cpp pin remain unchanged.
Full-model TP2 is refused before bootstrap. No 744B model is downloaded or run.
New `MAYA_GLM_PREFILL_STABLE` stays opt-in/off and is not locally performance
qualified. Fork-owned documentation is merged semantically; unsupported
platform-specific badges, translated READMEs and Docker instructions are not
restored. Numeric VERSION remains 1.1.44; no new fork release is requested.
