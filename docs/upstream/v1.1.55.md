## Semantic integration

Responses API namespace/builtin-tool and sealed-reasoning compatibility,
persistent resumable web answers and wake/reconnect changes are integrated.
Complete engine command serialization, per-request routing, sticky first-fatal
fanout, paired health/admin/restart guards and model-specific spec meanings
remain. Prompt memoization remains opt-in with MAYA/STRATA precedence, including
the loop guard; tests assert the fork behavior rather than upstream's new
on-by-default assumption.

The self-contained v53 `DS4_AI_RUN` prerequisite is now included to support
v55's indexer work: AIM bounds query/map allocation, score storage keeps its
original capacity, and run-sized row/stride values are used consistently by
all indexer/candidate/top-k consumers. `MAYA_DS4_AI_RUN=1` is opt-in; absent or
empty retains the original buffers/placement. STRATA and bare DS4 aliases
are supported, with MAYA precedence. Allocation, runtime and checked wire
identity use the same interpretation. A previously unused feature bit1
rejects mismatched rank choices in both control versions; batch launcher
execution digests include the normalized option. Legacy one-slot preflight
retains its three-field format. CPU/Python regressions cover disabled-mode
identity preservation, slots1/2/4 mismatch refusal and alias normalization.

GLM's automatic INT8 default and DeepSeek load-interleave default changes are
not adopted: existing explicit selections retain their behavior. The inherited
CUDA AR2 change remains guarded away from this fork's HIP target. Fork VERSION,
README/AGENTS identity, operational paths and llama.cpp pin are preserved.
The indexer feature is one scoped subset of deferred #133; that issue's other
experiments remain open. No pack/config or protected production edit is made.
